# AllocationLab Pilot Charter V1

## Purpose

This charter activates `AllocationLab` as a small real project member rather
than a long-lived placeholder.

The immediate aim is to make the project concrete enough to support early
research, discussion, and partner-facing exploration without pretending that a
full platform already exists.

## Pilot goal

Build a minimal AllocationLab pilot around the GreenYield concept:
- project-level evaluation
- sustainability and productivity scoring
- financing-condition awareness
- decision-support output for a small sample of projects

## Current basis

This charter is derived from:
- `projects/allocationlab/member_seed_decision_v1.md`
- `docs/projects/allocationlab/adapter_framing_v1.md`
- the GreenYield proposal summary provided by the user

The proposal already gives a useful pilot direction:
- project-level ranking rather than firm-level ESG scoring
- integration of sustainability, productivity, financing, and social impact
- sector-specific use in energy, transport, manufacturing, and agriculture

## Pilot scope

### In scope

- define a small project-card schema
- define a first scoring framework
- gather a very small sample of candidate projects
- produce one pilot ranking or comparison artifact
- write one short note on what a full roadmap would require

### Out of scope

- full optimization platform
- broad policy dashboard release
- deep automation or package extraction
- pretending the model is already production-ready

## Proposed first deliverables

1. GreenYield/AllocationLab pilot framing note
2. project-card schema v0
3. sample project set v0
4. pilot scoring logic v0
5. one comparison table or short pilot brief

## Suggested first technical shape

Recommended starting shape:
- a small manually curated sample
- explicit scoring dimensions
- one pilot notebook or script
- one short public-safe output artifact

Potential dimensions from the proposal:
- sustainability impact
- productivity gain
- financing ease or cost-of-capital sensitivity
- workforce or job implications
- public-image or stakeholder-risk dimension

## Success criteria

The pilot is successful if AllocationLab has:
- one explicit project schema
- one small sample
- one reproducible pilot scoring pass
- one short explanation of what the next full roadmap should be

## Planning posture

Recommended posture:
- keep AllocationLab planning project-scoped
- do not push it into the AI-washing roadmap machinery
- only create a heavier roadmap when a real pilot execution lane exists

## Bottom line

AllocationLab does not need a large system immediately.
It needs a credible pilot that shows what project-level decision support could
look like in this lab.
