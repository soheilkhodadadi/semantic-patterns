# Manuscript Assembly

This file is a human-readable index for the paper scaffold.

The actual build uses:

1. `paper/metadata.yaml`
2. the ordered section files in `paper/sections/`
3. optional `paper/reference.docx`

Use `make paper-build` to produce:

- `output/paper/manuscript_compiled.md`
- `output/doc/ai_washing_preliminary_draft.docx`
