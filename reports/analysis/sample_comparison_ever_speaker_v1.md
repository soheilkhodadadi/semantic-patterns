## Interpretation

The ever-speaker rebuild materially changes the empirical base:

- it keeps the same ever-speaker firm set
- it restores non-talking years
- it increases the usable estimation sample substantially
- it increases the number of patent-positive rows available for timing tests

That makes it a more credible base for:

- prior-patent alignment tests
- same-year versus future-year patent timing
- mismatch-style designs

The original mention-conditioned panel remains useful as a narrower conditional
validation sample, but it should no longer be treated as the only delivery-phase
panel.
