# AI-Washing Artifact Index V1

## Purpose

This is the first live project artifact to land in the normalized `ai_washing` member lane.
Its purpose is to make the current project state easy to navigate without changing existing authority.

It does three things:
- points to the current authoritative paper-support assets
- distinguishes main-text candidates from appendix or supporting objects
- records where fresh project-scoped artifacts should land next

The artifacts listed above remain authoritative in their existing locations.

## Fresh-work routing rule

When a new AI-washing artifact is created and it is not clearly manuscript-bound or shared-benchmark-bound, prefer these destinations first:
- tracked project reporting: `reports/projects/ai_washing/`
- polished project documents: `output/doc/projects/ai_washing/`
- polished project figures: `output/figures/projects/ai_washing/`
- curated project processed datasets: `data/processed/projects/ai_washing/`
