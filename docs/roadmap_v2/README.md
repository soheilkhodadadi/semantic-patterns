# Roadmap V2 Workspace

This folder is the public-safe workspace for the post-preliminary pivot.

Use it for:
- engine-boundary documents
- source-of-truth maps
- public-safe roadmap reviews
- FilingLens proof planning
- other strategy notes that are safe to keep in the repo

Do **not** use this folder for:
- partner-confidential notes
- interview prep that names private organizations or non-public terms
- NDA-bound materials
- negotiation notes or business-development notes you would not want in a public repo

Recommended split:

- public-safe tracked docs:
  - `docs/roadmap_v2/`
- local-private docs:
  - `local_private/roadmap_v2/`
