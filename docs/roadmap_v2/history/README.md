# Roadmap V2 History Buckets

## Purpose

This folder contains the operational-history buckets for `docs/roadmap_v2/`.

These files are still useful, but they are no longer the top-level front door
for understanding the current restructure state.

## Buckets

- `queues/`: per-cycle queue plans
- `comparisons/`: pre-queue fresh-authority comparisons
- `rounds/`: per-batch migration traces
- `checkpoints/`: per-queue posture summaries
