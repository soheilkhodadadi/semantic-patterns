# Lab Docs Workspace

This folder is the tracked documentation lane for the lab itself.

Use it for:
- stable control-plane documentation after it graduates from roadmap form
- shared schemas and evidence contracts
- migration records once the restructure is in flight
- onboarding notes for contributors working across multiple programs

Do not use it for:
- partner-confidential notes
- organization-specific strategy
- NDA-bound materials
- active manuscript prose

Current transition rule:
- strategy and migration planning still starts in `docs/roadmap_v2/`
- once a document becomes part of the durable operating model, promote it here
