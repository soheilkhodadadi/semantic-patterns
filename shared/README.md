# Shared

This lane is for cross-project assets that should not belong to only one project member.

Use it for:
- manifests
- labels
- evaluation assets
- shared registries

Do not use it for:
- project-specific semantics
- project-specific reports by default
- project-specific outputs by default

A good rule is:
- if an artifact mainly serves one project, keep it with that project
- if it stabilizes a cross-project asset family, it belongs here
